What survives when a provider disappears?

History, bytes, working programs, and independent services are not the same thing. Recover what's real, not what was merely named.

Archived

Wayback may preserve a prior public page, but a snapshot is not a current running service.

Recoverable

A verified capsule can restore the functions it actually contains, when its execution environment is available.

Live elsewhere

An independent host requires separate custody, authority, routing, receiver proof and recovery tests.

One real cold-start exemplar: 26/26 passed

A private user-chat ZIP containing three earlier self-contained research pages passed 26 local tests: clean extraction, 13 member-file checks, detection of missing/corrupted files, restoration from known-good bytes, offline Chromium rendering and interactions, mobile fit, zero external browser requests, and four local HTTP 200 reads.

Limits: The capsule remains a private chat download, not a public mirror or proven offsite custody. This testing environment blocked direct file navigation; independent offline per-page browser rendering and localhost HTTP readback were tested separately.

The most important missing relations

The GitHub-hosted CoRelay monitor previously passed 5/5 HTTP probes, but GitHub Pages, Raw, Actions, source and Issues still share a provider failure domain. A second GitHub URL is not independent redundancy.

Not yet proven: any independent remote forge or public origin, CoStead cold restore, CoGateway receiver, exact Wayback snapshot, current CoPolitic domain routing, or CoVIA delivery. The useful next test is recovery after GitHub itself becomes unavailable.

Feed back even the feedback

What if a backup contains the wrong version, an archive records withdrawn claims, a permission is revoked, an observer silently dies, or GitHub Issues itself becomes unavailable? Keep the negative result, trace its source, and choose a bounded repair, independent challenge, fallback or stop.

Machine-readable CoPhoenix contract · Voluntary public feedback. Do not put personal voter information or allegations in project issues.

Wayback is a witness, not an immortal worker

The Internet Archive warns that capture coverage and interactive replay can be incomplete. Save Page Now saves one requested page, not an entire linked site. No capture is claimed for this release.

CoPhoenix R0 is a test result and reusable protocol, not zero-failure assurance, restored private accounts or a new active runtime. No X2 access, paid media, Wayback submission, DNS mutation, bulk outreach or public mirror activation was performed.
