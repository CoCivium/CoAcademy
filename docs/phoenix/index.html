A healthy page check is not a healthy planet. Actual 5/5 readbacks are proof from a GitHub-hosted HTTP client, not off-GitHub restoration, independent user adoption, present health of other devices or unlimited autonomous repair. The risk report is generated per-run and can age or disappear with GitHub artifact retention.

The most important missing relations

The GitHub-hosted CoRelay monitor previously passed 5/5 HTTP probes, but GitHub Pages, Raw, Actions, source and Issues still share a provider failure domain. A second GitHub URL is not independent redundancy.

Not yet proven: any independent remote forge or public origin, CoStead cold restore, CoGateway receiver, exact Wayback snapshot, current CoPolitic domain routing, or CoVIA delivery. The useful next test is recovery after GitHub itself becomes unavailable.

Feed back even the feedback

What if a backup contains the wrong version, an archive records withdrawn claims, a permission is revoked, an observer silently dies, or GitHub Issues itself becomes unavailable? Keep the negative result, trace its source, and choose a bounded repair, independent challenge, fallback or stop.

Wayback is a witness, not an immortal worker

The Internet Archive warns that capture coverage and interactive replay can be incomplete. Save Page Now saves one requested page, not an entire linked site. No capture is claimed for this release.
