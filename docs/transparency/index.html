Public research · incomplete due diligence

Trust, without guesswork.

This page explains what the public CoAcademy experience is, what is known from its source, and what still needs independent checking. The unanswered questions are intentional. A template is not an excuse to manufacture assurances.

At a glance

Purpose

Experimental public learning and research. CoAcademy publishes interactive prototypes, inquiry methods and evidence-linked material. A working demo is not a production service guarantee.

Cost

This transparency page requests no payment. Any wider payments, sponsorships or recipients require separate verification. InSeed is reported as a commercial partner, not established as this site's operator.

Who legally operates it?

Unverified. Public GitHub source is under the CoCivium organization. Repository control does not establish a legal operator, privacy controller or contracting entity.

Privacy and data

Incomplete audit. This specific page has no analytics script or data form. Hosting logs, other pages, third parties and site-wide privacy practices have not been independently verified.

Licensing

Site-wide rights not proven. The main CoCivium repository contains GPLv3 text, but no root CoAcademy license was found in the bounded audit. Code and media rights must be checked per source.

Accessibility

Acceptance unverified. Responsive layout and some keyboard affordances are present, but this is not an accessibility certification or screen-reader test result.

AI involvement

Optional machine-readable descriptions and some AI-assisted research exist. No cross-provider agency, model sentience or automatic acceptance is claimed.

Corrections

Public, nonsensitive corrections can be proposed on GitHub. Do not post private information, credentials or vulnerability details there.

What to verify before making stronger claims

  • Legal operator and responsible privacy contact.
  • Site-wide data flows, access logging, subprocessors and retention.
  • Actual rights for code, text, generated media and third-party assets.
  • Independent accessibility and first-visit comprehension tests.
  • Verified private security reporting route before soliciting sensitive reports.
  • Any money, donations or sponsorships, naming the real recipient and legal terms.

The answers may differ across CoCivium, EntMent, InSeed and future sites. Their status must not be copied simply because the same page component is reused.

How this page is shared across sites

The shared versioned pattern supplies questions, evidence states and update rules. The CoAcademy-specific overlay supplies scoped facts, exceptions and unresolved issues. A site can reuse the former without inheriting unverified assertions from the latter.

Prior architecture: CoPublicConstellation, CoCommons source boundaries and contributor guidelines. This page is an operational disclosure prototype, not a replacement for laws or a complete formal privacy policy.
