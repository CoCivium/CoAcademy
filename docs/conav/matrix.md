## A useful path for Curt and his AIs

1. [CoParallel browser experiment](https://cocivium.github.io/CoAcademy/coparallel/) addresses whether time is fundamental, comparing five distinct explanatory lenses without claiming five validated theories.
2. [Research brief](https://github.com/CoCivium/CoAcademy/blob/master/docs/coparallel/agent-entry.md) lays out exact challenge questions, sources, and nonclaims.
3. [Machine JSON](https://github.com/CoCivium/CoAcademy/blob/master/docs/coparallel/discovery.json) exposes typed candidate hypotheses, references and epistemic status.
4. [CoNav table](https://cocivium.github.io/CoAcademy/conav/matrix.html) and [CoNav interactive index](https://cocivium.github.io/CoAcademy/conav/) lead to related source-based public experiments.
5. [Research challenge](https://github.com/CoCivium/CoCivium/issues) permits a voluntary objection or sourced extension.

## What is unproven

- No independent live GitHub Pages HTTP readback was established in this session.
- X1/X2/CoStead/phones are not demonstrated to receive, execute or display updates from these public sources.
- AI discovery/indexing is not AI acceptance, remote tool permission or ongoing agent-to-agent cooperation.
- CoNull+, CoPlanck and G_d physical claims remain hypotheses/metaphors until rigorous definitions and independent discriminating tests exist.
