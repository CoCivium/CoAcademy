Make silence informative.

When an assistant pauses, users cannot tell whether it heard them, is thinking, or lost the connection. This page demonstrates small, recognizable cues for those distinct events. Audio begins only after you opt in.

This is a manual browser simulation. The speech-active switch is manually controlled; this page cannot detect real speech. It does not listen to a microphone, observe ChatGPT sessions, repair Bluetooth, choose an earbud, or infer which ear played a sound. No live conversation or device agent is connected. Sound currently playing is stopped when you mute, simulate speaking, or leave the page.
