# CoCivicLens+ R1

A public, nonpartisan CoOrb/CoMap/CoNull civic learning prototype built from the earlier offline R0 experiment.

- **What exists:** one standalone HTML page with four topic nodes, four reader-selectable perspectives, source links, three fact-check exercises and a local-only note area.
- **How to use:** open the static page, select a topic/lens, and deliberately follow official sources. The page doesn't infer a reader's political views.
- **Official dates:** FEC lists Tuesday, November 3, 2026 as the regularly scheduled federal general election. Voting rules are state/local, and source links were reviewed October 24, 2026.
- **Privacy:** no analytics, cookies, accounts, input uploads or hidden sensors. Notes are in-page and vanish on reload. Clipboard use happens only on the button click.
- **Status:** public source, GitHub Pages deployment checked separately, no independent audience learning results.
- **Not:** a government voting service, party/candidate endorsement, official local rule finder, election prediction or a source of personal eligibility decisions.
