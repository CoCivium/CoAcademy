# CoPublicationAdaptiveLens+ R0A

State: PUBLIC-SAFE CANDIDATE · NOT CANON · NOT RUNTIME · NOT PUBLICATION AUTHORITY

## Purpose

Treat publication as an evidence-bearing relational surface rather than a one-shot post.

A publication object may carry:

- source/version/provenance
- audience and accessibility projections
- headline/title variants
- topic/content classification
- predecessor/successor relations
- timing/distribution experiments
- human-reader and AI-reader summaries
- challenge/correction paths
- currentness and stale-link checks
- measured comprehension/usefulness outcomes

## Candidate loop

```
source-bound publication
-> classify
-> generate bounded variants
-> test in shadow/private review
-> compare by receiver-relative outcomes
-> publish only through the existing public gate
-> observe
-> preserve corrections and disagreement
-> update Publication Atlas
```

## Fitness vector

Do not optimize one scalar such as clicks.

Candidate dimensions:

- comprehension
- truth calibration
- accessibility
- usefulness
- trust
- challenge yield
- provenance traceability
- reader effort
- correction cost
- discoverability
- latency/cost
- long-horizon value

## Headline / framing relation

A headline is a projection, not the underlying claim.

Humour, satire, mythic framing, mascots, and provocative variants may be useful when they remain visibly typed and preserve a factual translation path.

```
HEADLINE_NE_CLAIM
VIRAL_NE_VALID
ENGAGEMENT_NE_VALUE
SATIRE_NE_EVIDENCE
MASCOT_NE_AUTHORITY
AI_INTERPRETATION_NE_ACCEPTANCE
NEWER_NE_TRUER
```

## CoPublicationAtlas+ relation

Every published object should be addressable in a public index with:

- publication ID
- date/version
- canonical public URL
- short summary
- major claims and nonclaims
- predecessor/successor links
- related theory/education/media objects
- challenge/correction links
- machine-readable sidecar where practical

Individual posts should link to a small relevant neighborhood rather than dumping the whole archive.

## CoAcademy use

CoAcademy can teach publication literacy as part of inquiry literacy:

- distinguish claim from framing
- compare headlines without altering evidence
- recognize click-optimization failure modes
- inspect provenance and corrections
- test whether different readers reconstruct the same meaning
- practice public-safe translation of speculative or technical material

## Boundary

This candidate does not authorize publishing, outreach, targeting, profiling, recommendation manipulation, hidden persuasion, platform automation, or collection of private reader data.

Public release remains a separate gate.
