## How the intended parallelism works

**CoGlyphList+** holds unordered alternative hypotheses and parallel site-specific work. It cannot authorize work or create an execution order.

**CoTalkItOut+** provides resumable WorkID and authority concepts; the November R1 public version is planning/source evidence, not a deployed universal scheduler.

**CoGlyphRail+** is the ordered single-effect path: source → attribute → challenge → elect → test → verify → promote or rollback.

For a site's file tree, unshared candidate edits can be independently proposed. For shared pages, navigation, sitemap, common accessibility policy, licensing, deployment, DNS or payments, one elected integrator obtains an explicit lock/lease and merges verified evidence. Parallel review is allowed. Parallel uncoordinated shared writes are not.
