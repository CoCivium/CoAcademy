4. Preserve the truth and stop

For the current X2 WorkID exemplar, the proved boundary is: one local source audit committed; exact replays made no new result; conflicting bytes under the same WorkID were rejected. The overdue time was simulated and an independent receiver ACK was not observed.

source → typed question → bounded alternatives → negative test → exact result → HOLD / accept / retire → sleep

The CoZillion+ grammar already holds these relations. We are exposing a bounded slice, not minting 28 new CoTerms. A philosophical G_dSide value lens can guide questions about care and non-coercion but cannot promote a hypothesis to evidence or grant authority.
