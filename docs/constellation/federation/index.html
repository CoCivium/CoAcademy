3. Understand the seven safety tests

I1: No compulsory central brain

The already loaded page remains inspectable with the coordinator absent; no cold-boot independence claim.

I2: Discovery is not trust

No link or JSON entry is accepted as authority or receiver ACK.

I3: Authority does not flow through links

All scenarios forbid external writes; revocation and split-brain fail closed.

I4: Data classes stay separated

Public display excludes secrets and private identities; no synthetic customer data.

I5: Only one elected actuator

If there is no authorized sole writer, shared changes are held.

I6: Freshness must be explicit

Historic evidence is not current status and stale manifests cannot be green.

I7: Human and machine parity

This page's embedded fixture must match the machine-readable source contract.

The machine record is fixture.json. It carries exactly the same seven scenarios and explicit limits. The displayed state changes, never the record's authority.
