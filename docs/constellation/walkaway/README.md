# CoWalkaway+ | Steward-optional service, not operatorless authority

**15 November 2026 · Public-source execution contract R0 · Candidate, not an unattended CoAll runtime**

## CoHereNow

The product requirement is **the project's ordinary operations must not require its initiating human to keep a provider chat alive, transfer files, repeat approvals or re-explain currentness**. An authorized human still owns exceptional decisions concerning money, privacy, credentials, identity, rights, deletion, canon, and irreversible public or physical effects.

A quiet idle worker is success when there is no material, permitted work. "Rick not needed" means **no unnecessary human relay**; it does not mean consent has been granted forever or a person has been replaced.

## Typed CoGlyphList and CoTalkItOut relations

`MANY_CANDIDATES` are not `MANY_EXECUTED_WORKERS`. Work entries are distinct immutable WorkID+source-digest proposals. Optional patterns, alternatives, in-betweens, inversions, fan-in, translations and perspective relations **do not imply mandatory precedence, authority, or right to overwrite**.

- **Fan-out:** independent scoped site or research proposals; no overlapping file-writer leases
- **Fan-in:** exact-duplicate collapse with source digest; different payload under the same WorkID becomes `HOLD_CONFLICTING_VARIANTS`, not newest-wins
- **In-between:** site and source evidence may produce new links, but an edge cannot inherit authority from either endpoint
- **Inversion:** what if one human never comes back, a model session dies before committing, or a peer reports a false success?
- **Turtles:** maximum two challenge levels in this R0 canary; recursion is not a reason to renew an expired lease
- **G_dSide:** weigh safety, accessibility, correction, public benefit and avoided unnecessary human attention against compute and coordination costs; no private morality rank
- **Universal UX:** human summary, machine WorkID, exact source receipt, explicit Stop/HOLD and deep link to evidence are different views of one object, not independently mutable truths
- **Quiescence:** with no material change or permitted effect, stop. A dashboard indicator is not a mandate to keep waking providers

## One smallest safe CoDeed

Extend the **existing** GitHub Actions read-only workflow to run the deterministic fan-in canary on both public source events and its already scheduled daily run, with a short-lived receipt artifact. An independent observer should check its exact output, not claim an off-GitHub receiver. Do not create a new scheduled task, poller, second worker, DNS route or credential.

Then bind the actual authorized WorkID/CoOwnedWork receiver to one `no-change wake` and one `changed-source wake`, with the true independent receiver's readback. This remains the meaningful step before calling the initiating human operationally optional.
