# CoOrbWare First Look R0

**Public experimental CoCivium entrypoint.** 2026-10-24.

## What this is
A zero-account, source-linked educational projection of a proposed relational UX:
- CoOrb+: six user-selected nodes over a common source map.
- CoMap+: each node shows what is supported and where to inspect the original source.
- CoNull+: each node explicitly marks what is unknown, hypothetical or not yet proven.
- CoSeeker+: the reader chooses a path rather than being privately profiled.
- CoAfterglow+: a clear question or next action to take away.

This is NOT an installed OS, a remotely running AI agent, a deployment of CoOrbWare across devices or evidence of new physics/sentience. The visualized relations are curated navigation objects, not asserted physical network connections.

## Interaction rules
The page requires no login, cookies, analytic tags or third-party scripts. JavaScript updates only visible labels and links. Any network contact requires the visitor to click an external source. A noscript fallback provides source navigation.
