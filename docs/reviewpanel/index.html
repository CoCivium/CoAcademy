3. What review can and cannot prove

Observed: public HTTP response

The exact endpoint, status, MIME type and response size were measured. This can be rechecked, but it is a timestamped sample.

Unknown: task usefulness

HTTP 200 does not prove accessible navigation, comprehension, production reliability, rich-media quality, or independent human benefit.

Not allowed: fake consensus

A synthetic panel cannot vote itself independent. Role labels, repeated prompts and distinct fictional personas remain one class of simulated challenge.
