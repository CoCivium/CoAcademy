# CoAcademy

CoAcademy is a public learning and education surface for CoCivium material.

Start with [docs/](docs/). The directory structure and this README are navigation projections, not evidence that every educational object is current, validated or complete.

## Shared evolution intake

Capable sessions may contribute bounded **CoEducation+**, public-explanation, curriculum, glossary, challenge, example, and accessibility deltas through the shared [CoAll GitHub Evolution Fabric](https://github.com/CoCivium/CoCivium/blob/main/docs/Evolution/COALL_GITHUB_EVOLUTION_FABRIC_R0.md).

Educational projections should preserve source/currentness, epistemic status, uncertainty, and distinctions between hypothesis, metaphor, operational guidance, and evidence. Prefer material that helps a learner understand the relation field without pretending the teaching surface is the authority source.

Contributions should also preserve learner-relative context, accessibility, challenge paths and public-safe boundaries. Source/evidence status must remain visible in the educational projection.

Machine-facing contributors should consult the [evolution-lane registry](https://github.com/CoCivium/CoCivium/blob/main/ai/evolution-lanes.json) and the [CoEvoDelta v0.1 compatibility schema](https://github.com/CoCivium/CoCivium/blob/main/schemas/coevo-delta-v0.1.schema.json). Later schema candidates do not silently replace that compatibility contract.
