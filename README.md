# CoAcademy

CoAcademy is the public learning / education projection identified by the current CoAll repository-role map.

The repository currently exposes a `docs/` surface. This README is a lightweight navigation and contribution projection, not a claim that every educational object is current, validated or complete.

## CoEducation+ evolution intake

Capable sessions and workers should route education/public-learning deltas through the shared CoAll GitHub evolution fabric:

- https://github.com/CoCivium/CoCivium/blob/main/docs/Evolution/COALL_GITHUB_EVOLUTION_FABRIC_R0.md
- https://github.com/CoCivium/CoCivium/blob/main/ai/evolution-lanes.json
- https://github.com/CoCivium/CoCivium/blob/main/schemas/coevo-delta-v0.1.schema.json

Education contributions should preserve source/evidence status, learner-relative context, accessibility, uncertainty, challenge paths and public-safe boundaries.
