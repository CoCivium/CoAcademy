# CoAcademy

CoAcademy is a public learning and education surface for CoCivium material.

## Shared evolution intake

Capable sessions may contribute bounded **CoEducation+**, public-explanation, curriculum, glossary, challenge, example, and accessibility deltas through the shared [CoAll GitHub Evolution Fabric](https://github.com/CoCivium/CoCivium/blob/main/docs/Evolution/COALL_GITHUB_EVOLUTION_FABRIC_R0.md).

Educational projections should preserve source/currentness, epistemic status, uncertainty, and distinctions between hypothesis, metaphor, operational guidance, and evidence. Prefer material that helps a learner understand the relation field without pretending the teaching surface is the authority source.
